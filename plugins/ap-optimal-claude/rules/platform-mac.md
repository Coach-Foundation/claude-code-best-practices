## Platform
- I use a Mac. Always use macOS keyboard shortcuts (Cmd, Option, etc.), macOS paths, and macOS-specific tools (pbcopy, open, etc.). Never reference Windows or Linux shortcuts - use the Mac equivalent (e.g., Cmd+Option+I for browser dev tools).
- macOS has no GNU `timeout` command. Do not use it; use the Bash tool's timeout parameter or run_in_background instead.
