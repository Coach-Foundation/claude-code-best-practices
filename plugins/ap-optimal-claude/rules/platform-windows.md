## Platform
- I use Windows. Always use Windows keyboard shortcuts (Ctrl, Alt, etc.) and Windows-specific tools (e.g. `clip` to copy text, `start` to open a file). Never reference Mac shortcuts like Cmd - use the Windows equivalent (e.g., Ctrl+Shift+I or F12 for browser dev tools).
- You may have a PowerShell tool, a Bash tool (Git Bash), or both. In Bash commands write paths with forward slashes (`C:/Users/...` or `/c/Users/...`), since a backslash is an escape character there; in PowerShell normal Windows paths work. When telling me where a file is, use the normal Windows form (`C:\Users\...`). Python may be `python` or `py` rather than `python3`.
